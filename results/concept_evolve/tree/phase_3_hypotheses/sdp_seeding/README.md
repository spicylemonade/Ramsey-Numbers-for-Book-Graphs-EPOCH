# Concept: sdp_seeding

- Topic Context: Use semidefinite or spectral seeds only if they improve exact slack downstream.
- Domains: combinatorics, search

## Distinguishing Angle
- Why different from closest prior art: Introduces a different seed generator, not a new certificate.
- Easiest falsifier: No measurable improvement in exact slack search.
- First experiment: Seed the exact-slack baseline, not a stand-alone claim.
- Overlap risk: High overlap with generic continuous relaxations.
