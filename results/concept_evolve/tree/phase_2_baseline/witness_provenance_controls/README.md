# Concept: witness_provenance_controls

- Topic Context: Track where every supported witness comes from and which entries still lack external provenance.
- Domains: provenance, verification

## Distinguishing Angle
- Why different from closest prior art: Makes hidden provenance debt visible instead of silently trusting embedded strings.
- Easiest falsifier: Any supported witness presented as externally sourced without a citation trail.
- First experiment: Machine-readable provenance map plus source audit.
- Overlap risk: Low novelty, but critical to claim hygiene.
