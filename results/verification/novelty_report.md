## Problem-Local Sources

### Wesley, Lower Bounds for Book Ramsey Numbers
- Overlap status: real overlap and the main pivot trigger.
- Reason: same almost-diagonal target, same prime-power/block-circulant family, and the same computational neighborhood of SAT/IP/SMS witness search.
- Final differentiation: the attempted fixed-old-graph `n -> n+1` lift was a genuinely different search object, but it failed its own known-step recovery gate on `20 -> 21` and `21 -> 22`. No surviving novelty claim remains from that lane.

### Rousseau-Sheehan, On Ramsey Numbers for Books
- Overlap status: real local context, but not a novelty blocker for the implemented root artifact.
- Reason: classical theorem background and upper-bound context rather than the concrete packaged witness bank in the repo.
- Final differentiation: the root artifact does not claim new theory beyond that context.

### Conlon; Conlon-Fox-Wigderson; Chen-Lin; Liu-Li
- Overlap status: real local context.
- Reason: these are the correct book-Ramsey mathematical neighbors for claim boundaries, especially around upper bounds and asymptotics.
- Final differentiation: the repo does not derive a new asymptotic or extremal result from them and should not be described that way.

### Small Exact / Computational Sources
- Sources considered: Lidicky-McKinley-Pfender-Van Overberghe, Shao-Xu-Bo-Pan, Black-Leven-Radz, the `circulant-Ramsey` witness repository, and Wesley's computational discussion.
- Overlap status: real overlap for exact-witness search and heuristic baselines.
- Final differentiation: the exact pair-slack benchmark is only weakly different. It improved verifier-aligned slack margins on `24` and `50`, but it did not find a valid witness and therefore does not justify a publication-level novelty claim.

## Final Novelty Ruling

- Approved: the active root artifact is a deterministic, Python-only partial solver with explicit unsupported-input handling and a reproducible verification bundle.
- Approved: the experiment bundle provides negative evidence that the fixed-old completion lane is not a viable immediate extension and weak evidence that exact slack improved the primary `min_slack` metric on some unsupported cases, while the full verifier metric set remained mixed.
- Not approved: any claim of a full all-`n` construction, new theorem, new exact witness beyond the existing bank, or a solved frontier at `23`, `24`, `50`, or higher.
